# Google Apps Script Services

Kaltic uses Google Apps Script as a lightweight supporting service for selected processing tasks in the current MVP.

These scripts are called by the Joget application through HTTP POST requests.

They do not submit Cardano transactions directly. Cardano transactions and NFT minting are handled by the Cardano integration configured inside the Joget application.

---

## Services

### 1. Field Registration

File:

[`field-registration.gs`](field-registration.gs)

This service supports the agricultural field / plot registration workflow.

It performs the following operations:

- receives field GeoJSON generated by the Kaltic interface;
- canonicalizes the GeoJSON;
- calculates a SHA-256 hash of the canonical geographic record;
- calculates field area in hectares;
- generates a sequential field identifier;
- creates a satellite image representing the registered field;
- uploads the satellite image to IPFS through Pinata;
- returns the resulting hash, CID, image URL, area and field identifier to Joget.

The resulting information is subsequently used by the Joget workflow when creating the field record and minting its Cardano NFT.
