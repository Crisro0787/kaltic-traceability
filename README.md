# Kaltic

Kaltic is an agricultural traceability platform that creates verifiable Digital Product Passports for supply-chain records.

## Current status

Kaltic has a functional MVP operating on Cardano public testnet.

The platform currently includes:

- Farm registration
- Agricultural field/plot registration
- Harvest and traceability records
- Digital Product Passports
- Canonical traceability records and hashes
- Cardano testnet integration
- On-chain transaction evidence

## Architecture

Kaltic combines an application layer for operational and potentially sensitive supply-chain data with Cardano as a verification layer.

Current flow:

Traceability event → canonical record → cryptographic hash → Cardano transaction → Digital Product Passport
